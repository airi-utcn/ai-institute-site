## Quick answers

- **I saved but the site didn't change.** Saving only stores a draft. Click **Publish**. See
  [Save, Publish and Draft](./CONTENT_MANAGER_BASICS.md#save-publish-and-draft).
- **I published English but the Romanian page is empty.** Every language is published separately.
  See [Languages](./CONTENT_MANAGER_BASICS.md#languages).
- **Publish is refused with a validation error.** A required field is empty. The error names the
  field. News items need more fields than most, see
  [what a news item needs](./NEWS_AND_EVENTS.md#what-a-news-item-needs-before-publishing).
- **Who changed this?** Open the entry and use the `...` menu at the top right. See
  [Who last edited an entry](./CONTENT_MANAGER_BASICS.md#who-last-edited-an-entry).
- **A content type is missing from my menu.** Your role can't see it. Ask a maintainer.
- **The published site still shows the old version.** Pages are cached for up to about a minute.
  Wait, then reload.
